# 韩国文化爆款素材库

这个库用于持续沉淀可以改编成 HelloTalk 聊天记录的韩国相关知识点。目标不是收集普通百科知识，而是找到已经有传播信号、能让韩国人和外国人同时产生反应的内容母题。

## 入库门槛

每条素材至少满足以下一项，并且对应评分达到 4 分或 5 分：

1. 讨论度高：评论区存在争论、纠错、分享经历或身份代入。
2. 冲击感强：正常含义与脏话、成人含义、禁忌或刻板印象形成明显反差。
3. 认知度高：韩国人普遍知道，或海外 K-culture 受众容易认出。
4. 传播性强：不用长篇背景知识，三秒内能讲清核心冲突。
5. 出过爆款：存在可核验的高互动帖子、视频、二创或媒体报道。

不因“有趣”直接入库。语言梗必须核验真实词义、发音、语法和使用场景；社会文化必须区分事实、群体倾向、网络刻板印象和纯段子。

## 证据等级

| 等级 | 定义 |
|---|---|
| A | 有可访问的原帖互动数据，并有权威资料或多个独立来源核验 |
| B | 多个平台或媒体反复出现，但互动数据不完整 |
| C | 有明确讨论记录，仍需要补充平台数据或事实来源 |
| U | 用户已用内容表现或经验确认其爆款价值，后续继续补齐外部证据 |

平台数据必须记录采集日期。不得把搜索摘要、转载描述或估算数字伪装成原帖数据。

## 分类体系

- `语言/谐音`：近音词、外语耳误听、数字与脏话。
- `语言/双关`：普通词与成人、粗俗或禁忌含义重叠。
- `语言/语境`：单独查词与放进完整句子后的含义反差。
- `社交/关系`：前后辈、称呼、敬语、恋爱和朋友边界。
- `生活/习惯`：饮食、咖啡、作息、外卖、公共空间等。
- `网络/刻板印象`：韩国网民自嘲、外国人对韩国的固定想象。
- `韩剧/K-pop`：台词、饭圈行为、舞台文化和影视套路。

## 五维评分

每项 1-5 分：

- `discussion`：能否引发评论和争论。
- `shock`：反差和文化冲击强度。
- `recognition`：目标受众的认知基础。
- `spread`：是否能用一句封面文案讲清。
- `viral_proof`：是否有真实爆款或大量二创证据。

优先级：

- `S`：总分 22-25，可直接开发。
- `A`：总分 18-21，适合进入选题池。
- `B`：总分 14-17，需要更好的切入角度。
- 低于 14 分不进入主库。

## 每日工作流

1. 读取 `materials.jsonl`、`dialogues.json` 和 `素材索引.md`，先查重。
2. 搜索 TikTok、Instagram、X、抖音、小红书，并补充 YouTube、Reddit、韩国论坛和媒体信号。
3. 至少找到 1 条达到入库门槛的新素材。
4. 保存原帖链接、可见互动量、发布时间、采集日期和评论争议点。
5. 用韩国官方词典、韩国主流媒体或至少两个独立来源核验事实。
6. 标注敏感性、刻板印象风险和容易写错的边界。
7. 追加到 `materials.jsonl`，并在 `dialogues.json` 为同一 ID 添加两版经过校对的双语聊天文案。
8. 同步更新 `素材索引.md`，在 `daily/日期.md` 留下搜索过的平台、未入库候选和淘汰原因。

## 对话改编标准

- “我”是美国女生，“对方”是韩国男生，两人是身处不同国家的熟悉网友。
- 误会必须有真实语言或文化依据，人物不能为了笑点降智。
- 每句话自然回应上一句，避免教师式说明和刻意金句。
- 对话使用短句、停顿、追问、`ㅋㅋㅋ` 和朋友式互怼。
- 每段提供中文和 English；韩语原句在标题下单独解释。
- 不写线下共同活动，不默认暧昧；是否使用轻微成人感由具体选题决定。
- 每条素材至少提供 2 个版本，每版 5-10 句，角色字段只使用 `我` 和 `对方`。
- 封面最多三行：韩语关键词、中文 A 还是 B、English A or B。
- 敏感词、脏话和成人双关必须写明成立语境，不得扩大为任何情况下都成立。

## 文案蓝图格式

`dialogues.json` 使用素材 ID 作为键。每条记录必须包含：

```json
{
  "KR-LANG-001": {
    "korean_original": "韩语原句",
    "meaning_zh": "中文含义",
    "meaning_en": "English meaning",
    "reason_zh": "中文误会原因与语境边界",
    "reason_en": "English explanation and context boundary",
    "cover_zh": "A 还是 B？",
    "cover_en": "A or B?",
    "variants": [
      [
        {
          "role": "我",
          "zh": "中文消息",
          "en": "English message"
        }
      ]
    ]
  }
}
```

新增素材时，`materials.jsonl` 与 `dialogues.json` 的 ID 必须一一对应。提交前需要验证 JSON、版本数量、每版句数、角色字段和中英双语字段。

## 文件说明

- `materials.jsonl`：机器可读的素材主库，一行一条 JSON。
- `dialogues.json`：文案工坊使用的逐素材双语文案蓝图。
- `素材索引.md`：人工浏览和选题使用的简表。
- `daily/`：每日搜索记录、候选和淘汰项。
