## 当前优先开发

1. `Hongdae Guy / Are you open mindeu?`：平台数据和争议链完整，可直接开发美国女生与韩国男网友讨论“为什么外国女生都认识这句”的聊天。
2. `얼죽아`：低敏感、认知广，可与美国人的冰咖啡习惯自然对比。
3. `우리 남편`：一句话即可触发“为什么是我们的老公”的真实误会。
4. `관계 / 연애`：适合做“词典查relationship却写成成人自曝”的低门槛聊天误会。
5. `오빠 / 형 / 친오빠`：认知度极高，可做“欧巴到底是哥哥还是男朋友”的称呼边界互怼。
6. `깻잎 논쟁`：TikTok、YouTube和韩国媒体证据完整，可做“礼貌还是越界”的跨文化关系观争论。
7. `한국 나이 / 만 나이`：TikTok原帖互动强，官方法律转型和国际媒体解释完整，可做“出生1岁还是0岁”的低门槛文化冲突。
8. `아줌마 / 아저씨 / 사장님 / 선생님`：称呼边界清晰，词典义与现实语用有反差，可做“阿姨大叔还是老板老师”的聊天误会。
9. `눈치 / 눈치 없다 / 눈치 챙겨`：韩国人熟知的读空气社交语用词，可做“眼力见还是读心术”的跨文化误解。
10. `라떼는 말이야 / 나 때는 말이야 / 꼰대`：咖啡谐音和职场说教反差清晰，可做“拿铁还是老前辈说教”的朋友互怼。
11. `읽씹 / 안읽씹 / 카톡 1`：聊天已读提示和不回消息的心理压力清晰，可做“已读不回还是没读也不回”的异国时差互怼。
12. `JMT / 존맛탱 / 존맛탱구리`：英文缩写外观和韩语俗语语感反差强，可做“好吃还是粗口缩写”的美食评论误会。
13. `개웃겨 / 개꿀잼 / 개이득 / 개-`：字面狗义和韩网强烈程度前缀反差直观，可做“狗还是超好笑”的词典直译误会。
14. `썸 타다 / 썸 / 썸타는 중`：英语something外来形和韩式暧昧阶段语义反差清楚，可做“朋友还是暧昧”的线上聊天边界互怼。
